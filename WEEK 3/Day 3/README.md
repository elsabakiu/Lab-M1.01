# LangChain Hello Reply (Week 3 / Day 3)

Simple scaffold that sends `hello` and prints the model's reply using LangChain.

## Setup

1. Create and activate a virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set your API key:
   ```bash
   cp .env.example .env
   ```
   Then edit `.env` and add your real `OPENAI_API_KEY`.

## Run

```bash
python src/main.py
```
