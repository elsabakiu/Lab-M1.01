# Dashboard Documentation

## Dashboard Objective

Build a stakeholder-friendly dashboard for a mid-sized outpatient clinic that highlights:

- appointment volume
- no-show patterns
- provider utilization
- reminder effectiveness
- AI-generated operational insights

## Delivery Choice

This project intentionally delivers the dashboard in Plotly and Streamlit.

This delivery choice supports a more integrated demo experience:

- Plotly gives the project richer code-driven visuals that can live in the same repository as the data and AI logic
- Streamlit makes the dashboard portable and easy to run from a clean clone
- the combined interface supports KPI review, AI Q&A, risk analysis, and workflow triggering in one place

The intended final presentation layer is the Streamlit application.

## Transparency Model

The dashboard intentionally separates content into three types:

- Observed data
  Appointment volume, no-show patterns, utilization, and lead-time views are computed directly from the processed dataset.
- AI-generated insight
  Chatbot responses, insight cards, and risk prioritization are generated by the analytics agent from the same processed inputs.
- Modeled business estimate
  ROI scenarios, implementation comparisons, and business impact framing are strategic estimates rather than directly observed outcomes.

This distinction is made explicit in the UI so stakeholders can tell the difference between measured operations, AI interpretation, and projected business value.

## Streamlit Information Architecture

### Executive Dashboard

- KPI cards: total appointments, no-show rate, average wait time, reminder coverage
- line chart: daily appointments and no-show trend
- bar and heatmap views for no-show and utilization patterns
- AI insight cards for recommended next actions

### Risk Board

- daily no-show risk distribution
- scored appointment table for triage and outreach prioritization

### Appointments And Communication Logs

- appointment activity views
- communication log summaries
- access to live Airtable data when available

### Workflow Handoff

- n8n trigger point for operational follow-up
- response feedback after workflow execution

## Refresh Process

1. Add or replace the raw CSV in `data/raw/`.
2. Run `python data/data_prep.py`.
3. Run `python agent/run_agent.py`.
4. Launch `streamlit run streamlit_app.py`.
